# DMIT 洛杉磯：LAX Pro／EB／T1 三條線路差在哪，全套餐價格與挑選順序一次講清楚

會去搜「DMIT 洛杉磯」的人，通常已經知道這家是做精品線路的美西 VPS，真正卡住的地方往往不是「要不要買」，而是三個更具體的問題：Pro、EB、T1 到底差在哪、為什麼同價位流量差一大截、以及官網一堆品項顯示缺貨時到底該等哪一款。

這篇不鋪品牌故事，直接從線路、配置、價格一路講到下單前要看清楚的細節。

## 洛杉磯機房分成三條線路，選錯比買貴更虧

DMIT 把洛杉磯（LAX）的機器按網路品質分成三個系列，官方命名是 Premium、Eyeball、Tier 1，社群裡通常簡寫成 Pro、EB、T1。

**Premium（Pro）** 是招牌線路。電信去程走 AS4809（CN2 GIA），聯通去程直連 AS4837，移動去程經香港移動 AS58453，三網回程統一走 AS4809。對電信寬帶用戶來說，這是三個系列裡最穩的一條，晚高峰的抖動和丟包控制得住。要注意一個細節：洛杉磯 Pro 的 IPv6 回程**不是**走 CN2 GIA，而是 CMIN2／9929 動態均衡，所以如果你的應用默認走 IPv6，實際體驗會和 IPv4 有落差。

**Eyeball（EB）** 走 CMIN2 為主。電信回程在 AS9929 與 AS58807 之間做負載均衡，聯通主要走 AS9929，移動走 CMIN2。移動寬帶用戶選這條，性價比最高——同樣的價格，EB 給的流量通常比 Pro 多五成到一倍。

**Tier 1（T1）** 是純國際 BGP 線路，去程回程都沒有針對中國大陸做優化。它的賣點是便宜和流量大，T1 系列還是單向計費（取進出方向較大者），適合海外建站、中轉落地、CI/CD 跑批次這類本來就不在意中國路由的場景。

三個系列都有一個共同的設計：**流量用完不會斷線**。Pro 與 EB 的 TINY、Pocket 會降到 4Mbps 繼續跑，MINI、MICRO 降到 8Mbps，更高階的降到 10Mbps；T1 更寬鬆，超量後維持 100～200Mbps。這條政策對流量估算不準的人來說很實用，至少不會半夜業務直接掛掉。

## AS3、AN4、AN5 差在哪，值不值得加價

同一個洛杉磯 Pro，官網會列出不同「世代」，差別在 CPU 平台：

- **AS3**：AMD EPYC 7003 系列，目前洛杉磯最便宜的一檔
- **AN4**：AMD EPYC 9004 系列，同規格價格貴一級，例如 Pro.MINI 從 $62.90 拉到 $72.90，Pro.MICRO 從 $87.90 拉到 $102.90，Pro.MEDIUM 從 $199.90 拉到 $239.90
- **AN5**：AMD EPYC 9005 系列，規格更新、價格再往上，具體數字各來源整理不一致，買前建議直接看官網

判斷方式不複雜：**同世代價格一樣、線路一樣、流量一樣**，你多付的錢基本只買到更新的 CPU。如果用途是建站、WordPress、反向代理、跑輕量容器，AS3 的 EPYC 7003 已經綽綽有餘；只有在跑編譯、影片轉碼、資料庫這類吃單核與記憶體頻寬的負載時，AN4／AN5 的價差才比較容易回本。

還有一點值得留意：官方曾提示部分較新平台仍在持續優化階段，磁碟效能與 SLA 可能低於成熟平台。要放重要業務的話，先用月付跑一段時間再決定要不要轉年付。

## 折扣碼與補貨：DMIT 的價格邏輯跟別家不一樣

大部分主機商靠常年折扣碼拉客，DMIT 不太走這條路，它的低價主要來自兩件事：

**一是限量特價款。** MALIBU、PalmSpring、CORONA 這類用加州地名命名的款式，價格明顯低於常規套餐（例如 1 核 1G／20G SSD／1000GB 流量的 MALIBU 年付約 $49.9），但數量有限、賣完就下架，什麼時候補貨沒有固定規律。想蹲這類款式，通常得靠補貨通知群或監控。

**二是循環折扣碼。** EB 系列曾推出季付以上可用的循環 8 折碼 `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF`，屬於長期有效的循環折扣而非一次性優惠。不過 DMIT 的優惠碼汰換頻繁，能否生效要在結帳頁實際試一次才算數，我不建議把它當成必然發生的折扣來規劃預算。

有一件事倒是很常見：**缺貨比漲價更常發生**。熱門低價款經常在補貨後幾小時內清空，如果你已經確定要買，等折扣的期望值通常不如直接下單。

## 下單前要確認的幾件事

**付款方式**：支援支付寶、PayPal 與信用卡，對中文用戶來說門檻不高。

**退款政策**：購買 3 天內且累計流量不超過 30GB，可全額退款；30 天內可按剩餘使用時長或流量比例退款，但會扣除支付網關手續費。這條政策決定了正確的下單順序——**先買月付測試，滿意再考慮年付**。

**更換 IP**：IP 被牆或無法正常使用時，可申請免費更換 IP，頻率為每 15 天一次；後台也逐步支援自助換 IP。

**訂單時效**：下單後未付款的訂單約 3 小時會自動取消，蹲補貨時不用擔心佔不到庫存，但也別拖太久。

**先測再買**：DMIT 有公開的 Looking Glass 測速入口（lg.dmit.sh），分 lax-pro、lax-eb、lax-t1 三個節點。買之前從自己的網路環境 tracert 一下回程路由，比看任何測評都準。

## 常見問題

**洛杉磯每個系列都有 CN2 GIA 嗎？**
不是。只有 Premium（Pro）系列走 CN2 GIA。EB 是 CMIN2 加 9929，T1 是純國際 BGP，兩者都沒有 CN2 GIA 回程。

**流量用完會直接停機嗎？**
不會。Pro 與 EB 超量後降到 4～10Mbps 繼續不限量使用，T1 更是維持 100～200Mbps。降速幅度按套餐檔位區分，檔位越高保留的頻寬越大。

**月付和年付怎麼選？**
退款政策允許 3 天內全額退（流量≤30GB），所以最穩的做法是月付實測路由與效能，確認沒問題再轉年付或季付。年付通常有折扣，但不值得為折扣跳過測試這一步。

**為什麼同樣配置，不同世代的價格差這麼多？**
差在 CPU 平台。AS3 是 EPYC 7003、AN4 是 EPYC 9004、AN5 是 EPYC 9005，線路與流量配置相同，價格差距完全是硬體世代帶來的。輕量用途沒必要追新。

**官網顯示缺貨怎麼辦？**
洛杉磯熱門款確實經常缺貨，補貨時間不固定，通常會在原補貨週期後陸續上架。著急用的話，同系列其他檔位或較低價的 T1 系列通常還有貨。
